# 44 — Supports de soutenance

Date : 30 octobre 2026.

L’auteur demande un PowerPoint et une version LaTeX. Le contenu commun est décliné en PowerPoint modifiable et en Beamer compilé. Dix-huit diapositives forment le parcours principal ; deux compléments répondent aux questions sur la réservation et la régression.

Les valeurs sont reprises des archives du mémoire. Les succès du modèle structuré sont associés aux départs contrôlés ; la navigation reste une chaîne hybride. Le support précise explicitement que la simulation est en 2D. Les notes conservent les sources, les explications et les limites.

Les figures scientifiques existantes sont réutilisées. La source Beamer, ses figures vectorielles et ses notes sont livrées dans une archive autonome. Les présentations ne modifient ni le modèle ni les conclusions des campagnes.
